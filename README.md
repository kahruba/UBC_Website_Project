# 🎓 UBC Website Project

A multi-page university website inspired by the **University of British Columbia (UBC)**. This project provides a clean and organized university website experience using **HTML5 and CSS3**, featuring information about the university, its campuses, faculties, admissions, and user interface pages.

The website is developed as a front-end academic project to practice website structure, navigation, styling, image integration, and multi-page web development.

## 🌐 Live Website

**Visit the Website:** [UBC Website Project](https://kahruba.github.io/UBC_Website_Project/)

Explore the website online to view its pages, design, navigation, and university-related information.

## 🚀 Getting Started

### Prerequisites

You will need:
- A modern web browser
- Visual Studio Code or another code editor
- Git (optional)

### Run Locally

**1. Clone the repository**

```bash
git clone https://github.com/kahruba/UBC_Website_Project.git
```

**2. Navigate to the project directory**

```bash
cd UBC_Website_Project
```

**3. Open the website**

Open `index.html` in your browser, or open the project in Visual Studio Code and use the Live Server extension.

## 🧑‍💻 Usage Guide

1. Open the website homepage.
2. Use the navigation bar to explore the different sections.
3. Visit the About UBC page to learn about the university.
4. Explore the campuses page for Vancouver and Okanagan campus information.
5. Visit the faculties page to explore academic information.
6. Browse the admissions page for admission-related content.
7. Explore the login and registration interfaces.
8. View the dashboard interface.
