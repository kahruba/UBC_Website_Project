# 🎓 UBC Website Project

A multi-page university website project inspired by the **University of British Columbia (UBC)**. This project presents a clean and organized university website experience using **HTML5 and CSS3**, featuring information about the university, its campuses, faculties, admissions, and a login page.

The website is designed as a front-end academic project to practice website structure, navigation, styling, image handling, and multi-page web development.

## 🚀 Getting Started

### Prerequisites

You only need:

* A modern web browser
* VS Code or another code editor
* Git (optional)

### Run Locally

Clone the repository:

```bash
git clone https://github.com/kahruba/UBC_Website_Project.git
```

Go to the project directory:

```bash
cd UBC_Website_Project
```

Then open `index.html` in your browser.

You can also open the project directly in **VS Code** and use a local development extension such as Live Server.

## 🧑‍💻 Usage Guide
